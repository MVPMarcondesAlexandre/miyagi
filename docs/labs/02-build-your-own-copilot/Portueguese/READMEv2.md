# Introdução ao Miyagi

### Duração estimada: 10 minutos

O Miyagi foi criado para demonstrar o Microsoft Copilot Stack na criação e implantação de aplicações inteligentes avançadas e empresariais. Esta iniciativa oferece uma exploração abrangente tanto de casos de uso de aprendizado de máquina generativo quanto tradicional, proporcionando uma abordagem prática para desenvolver experiências de produtos aprimoradas com IA.

Este workshop é voltado para engenheiros de software interessados em mergulhar em padrões e técnicas emergentes de design que elevam suas aplicações por meio da hiperpersonalização e do aumento da produtividade.

## Objetivo

Neste workshop prático, você aprenderá a utilizar o Microsoft Copilot Stack para projetar e construir aplicações empresariais com IA que aumentem a produtividade e entreguem experiências de usuário altamente personalizadas.

- **Interaja com ferramentas e metodologias:** Aprenda técnicas de prompt engineering (como *chain-of-thought*, *retrieval-augmentation*), vetorização para memória de longo prazo e ajuste fino de modelos open source.
- **Introduzir conceitos avançados:** Explore orquestração estilo agente e plugins para potencializar modelos de linguagem grande (LLMs).
- **Construir uma base para integração de IA:**: Forneça uma base sólida para integrar IA em aplicações modernas.

## Principais Habilidades e Ferramentas

- **IA Generativa:** Compreensão dos fundamentos e aplicações.
- **Azure OpenAI:** Implementação de soluções de IA usando os serviços OpenAI do Azure.
- **Padrões Retrieval Augmented Generation (RAG):** Aprimoramento de modelos de IA com RAG.
- **Semantic Kernel:** Utilização do Semantic Kernel para tarefas guiadas por IA.
- **Microsoft Copilot Stack:** Aproveitamento do Copilot Stack para construir sistemas inteligentes.
- **Casos de Uso Práticos:** Aplicação do conhecimento em cenários reais para idealizar e criar soluções inteligentes.

## Público Alvo
Este workshop é indicado para:

- **Desenvolvedores e arquitetos** com conhecimentos básicos em desenvolvimento de aplicações que desejam incorporar IA em seus apps.
- **Gerentes de produto e designers** interessados em utilizar IA para melhorar experiências dos usuários.
- Qualquer pessoa curiosa sobre o potencial da IA no desenvolvimento de aplicações.
